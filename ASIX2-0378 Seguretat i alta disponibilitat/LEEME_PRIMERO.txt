QUE SUBIR A GITHUB (esta carpeta replica la estructura del repositorio)
=======================================================================

En el repositorio https://github.com/krysp4/Clases, dentro de la carpeta
"ASIX2-0378 Seguretat i alta disponibilitat", hay que tener esto:

  SUBIR (todo lo que hay en esta carpeta menos este archivo):

  README.md                                   -> descripcion del proyecto
  NoteBook/Proyecto_Analisis_Datos.ipynb      -> el notebook (ya ejecutado, con resultados)
  NoteBook/datos_ficticios_..._ampliado.csv   -> el dataset (tiene que estar junto al notebook)
  NoteBook/graficos/*.png                     -> los 8 graficos del informe
  Informe/Adri Alonso - Alvaro Haoan - ASIX 3078.docx -> informe completo

  NO SUBIR / BORRAR:

  - NoteBook/Untitled.ipynb                   -> vacio, se puede borrar
  - NoteBook/.ipynb_checkpoints/              -> carpeta temporal de Jupyter
  - Este archivo (LEEME_PRIMERO.txt)

  YA ESTAN EN EL REPOSITORIO (no hace falta tocarlos):

  - NoteBook/Pokemon/ y NoteBook/famosos.ipynb  -> ejercicios de clase
  - datos_ficticios_..._ampliado.csv en la carpeta principal (puede quedarse)

COMO SUBIRLO (desde la terminal, en la carpeta del repositorio clonado)
-----------------------------------------------------------------------
  git pull
  (copiar el contenido de SUBIR_A_GITHUB dentro de "ASIX2-0378 Seguretat i alta disponibilitat")
  git rm "ASIX2-0378 Seguretat i alta disponibilitat/NoteBook/Untitled.ipynb"
  git add .
  git commit -m "Proyecto analisis de datos: notebook, graficos e informe"
  git push

Y para que el companero pueda trabajar: en GitHub > Settings > Collaborators > Add people.
