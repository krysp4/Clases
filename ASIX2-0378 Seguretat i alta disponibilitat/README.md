# Proyecto: Análisis de un conjunto de datos (uso del ordenador)

Módulo 0378 - Seguridad y alta disponibilidad (ASIX2)
Autores: Adri Alonso, Álvaro y Haoan

Análisis de un dataset de 500 personas ficticias con datos sobre el uso del ordenador e internet
(horas al día, provincia, estudios, situación laboral, dispositivo, formación en ciberseguridad...).

## Contenido

- `NoteBook/Proyecto_Analisis_Datos.ipynb`: notebook con la exploración, los gráficos y las preguntas.
- `NoteBook/datos_ficticios_uso_ordenador_500_personas_ampliado.csv`: dataset.
- `NoteBook/graficos/`: gráficos que genera el notebook (los usamos en el informe).
- `Informe/`: informe en Word.

## Cómo ejecutarlo

1. Instalar las librerías: `pip install pandas numpy matplotlib seaborn notebook`
2. Abrir Jupyter en la carpeta `NoteBook`: `jupyter notebook`
3. Abrir `Proyecto_Analisis_Datos.ipynb` y ejecutar todas las celdas (Run > Run All Cells).

Versión de Python usada: 3.13.1
